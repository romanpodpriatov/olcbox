### Before you update on Android

ProofKit now installs as `org.proofkit.app`, the same identifier the iOS app uses, so it no longer collides with other apps built from olcbox. This build installs **next to** the old one and your server lists do not carry over: open the old app once, share or copy each list link, add them in the new app (or tap the link from your bot or panel), then uninstall the old app.

### One-tap links

Links from a provider's bot or panel (`https://proofkit.org/add#…` or `proofkit://add?url=…`) now open straight in the app on iOS, Android, macOS and Linux and add the server list. On Windows, copy the link from the page and paste it under Add.
